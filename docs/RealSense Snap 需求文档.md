# RealSense Snap 需求文档

## 引言

上海瀛宇公司能力考核。旨在验证基于Intel RealSense深度摄像头的计算机视觉算法应用能力。

**任务1：自由切换背景的照相软件**
描述：借助RealSense摄像头，人站在摄像头前面拍照，可以自由切换人后面的背景，人的轮廓要清晰平滑

**任务2：眉心与体温识别**
描述：可以根据人的眼睛位置，使用摄像头，实时识别人的眉心位置，并检测出当前人的体温

## 总体描述

### 用户角色

**操作员**：坐在摄像头前，通过 GUI 按钮进行拍照、切换背景、查看温度数据。

### 运行环境约束

- **硬件底座**：搭载 Intel USB 3.0 控制器的 PC / Mac。
- **操作系统**：Windows 10/11 或 macOS 12+。
- **显示设备**：屏幕分辨率不低于 1280x720。

## 功能需求（FR）

| 编号                  | 需求描述（采用 EARS 语法）                                   | 验收标准 / 优先级             |
| :-------------------- | :----------------------------------------------------------- | :---------------------------- |
| **FR-01**             | 系统应枚举并连接当前 PC 上的 RealSense 设备，**当** 设备连接失败时，UI 界面应显示“未检测到摄像头”的悬浮提示。 | **高**                        |
| **FR-02**             | 系统应以 **30fps** 的帧率实时显示彩色画面，                  | **高**                        |
| **FR-03（核心）**     | **当** 操作员点击“拍照”按钮时，系统应捕获当前帧的彩色图与深度图，并利用深度阈值（或 AI 分割）生成人物前景蒙版（Mask）。 | **高**                        |
| **FR-04（边缘质量）** | 生成的抠图蒙版边缘必须进行 **2px 羽化（Gaussian Blur）** 处理，确保人物发丝与身体边缘平滑，无硬边锯齿。 | **高** （这是考核视觉加分项） |
| **FR-05**             | 系统应内置“背景库”（至少 3 张默认背景图），并支持操作员通过文件浏览器 **本地加载** 自定义背景图片（支持 .jpg/.png 格式）。 | **中**                        |
| **FR-06**             | **当** 操作员点击“保存照片”时，系统应将“人物前景 + 所选背景”融合后的图像保存至本地磁盘（`~/Pictures/` 目录），文件名包含时间戳。 | **高**                        |
| **FR-07（眉心识别）** | 系统应实时检测人脸 68 个关键点，计算 **左右瞳孔中心点连线的中点** 作为“眉心”，并在视频画面上用 **红色十字准星** 实时绘制。 | **高**                        |
| **FR-08**             | 系统应在 UI 侧边栏 **实时显示** 眉心点在空间坐标系中的相对位移（X, Y, Z 坐标值）。 | **中**                        |
| **FR-09**             | 系统提供彩色图-深度图对齐显示功能，可手动开关并调节像素叠加比。 | 低                            |

## 非功能需求（NFR）

| 编号       | 需求描述                                                     | 测量指标                                              |
| :--------- | :----------------------------------------------------------- | :---------------------------------------------------- |
| **NFR-01** | **实时性（延迟）**：从摄像头捕获到 UI 屏幕显示，端到端延迟。 | **≤ 100ms**（保证手动操作跟手）                       |
| **NFR-02** | **算力占用**：CPU 占用率（后台主线程）。                     | **≤ 单核 60%**（必须使用子线程`CameraWorker`）        |
| **NFR-03** | **内存泄漏**：长时间运行。                                   | 连续运行 **1 小时**，内存占用增长不超过初始值的 10%。 |
| **NFR-04** | **易用性**：核心操作（拍照、换背景）按钮需显著置于主界面，操作步骤不超过 **2 步**。 | 无                                                    |

## 外部接口需求（EIR）

| 编号       | 需求描述                                                     |
| :--------- | :----------------------------------------------------------- |
| **EIR-01** | **硬件驱动**：需安装 Intel RealSense SDK 2.0 (v2.54+)，相机固件版本需为 5.16+。 |
| **EIR-02** | **软件框架**：依赖 **Qt 6.11**（GUI 框架）、**OpenCV 4.10**（图像处理与关键点检测）。 |
| **EIR-03** | **第三方算法库**：眉心关键点检测依赖 OpenCV 预训练的 `haarcascade_eye` 或 `shape_predictor_68_face_landmarks.dat` 模型。*需确保模型文件随 APP 打包分发。* |
| **EIR-04** | **安装包布局**：安装后的 `.app` (macOS) 或 `.exe` (Windows) 需包含所有依赖动态库，且**不得**依赖开发机上的绝对路径（需设置好 `INSTALL_RPATH`）。 |

### 6.2 界面原型描述

- **主窗口**：左侧 70% 区域为 `VideoItem` 实时视频画面，右侧 30% 区域为控制面板（换背景、拍照、显示眉心坐标）。
- **叠加层**：在 `VideoItem` 上，使用 QML `Canvas` 或 C++ 绘制红色十字线。
